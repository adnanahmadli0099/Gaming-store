# Local Business Website Demo

A responsive, multi-section website starter for the business in the supplied Google Business Profile URL.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, use a local static server or VS Code Live Server.
3. Edit business details and copy in `index.html`.
4. Customize colors and layouts in `styles.css`.
5. Customize navigation and form validation in `script.js`.

## Important before launch
- Business details are placeholders because the Google listing could not be verified.
- Replace all bracketed placeholders with owner-approved facts.
- Photos are remote Unsplash demo imagery. Replace with licensed, approved images relevant to the actual business.
- The contact form only validates in the browser. It does NOT send email or save enquiries. Connect a secure form endpoint before production.
- Replace the demo logo mark and update the page title/meta description.
- Add a real privacy policy and verified map, phone, WhatsApp, hours, and review links where applicable.
- External fonts and demo images require an internet connection.
